ROBOT ARCHITECTURE // SPEC V3

The Machine: Night Fury

Night Fury is PMR Phoenix's DECODE robot, built around one core philosophy: speed wins. Carbon-fibre chassis, gecko-wheel intake transfer, and precision dual-flywheel turret.

HARDWARE SPEC V3

Competition Chassis

Custom carbon-fibre plates, high-speed 4-motor belted drivetrain, and low-center-of-gravity electronics layout.

QUALIFIER RECORD

Tournament Proven

Earned Design, Think, and Innovate Awards while setting the provincial scoring record for British Columbia.

SPEC.01 // RAPID CYCLE 27S → <3S

Sub-3s Cycle Times

Cycle time reduced from 27 seconds to under 3 seconds across four generations of rapid physical iteration.

SPEED GAIN +900% FASTER
SPEC.02 // AUTONOMOUS 18-BALL PATH

18-Ball Autonomous

Powered by PedroPathing and precision dead-wheel odometry, maintaining a 90% target shooting accuracy.

FIELD ACCURACY 90% HIT RATE
SPEC.03 // TURRET CLOSED-LOOP PID

Dual-Flywheel Turret

Gecko-wheel transfer feed with closed-loop PID flywheel motors and a dynamic servo-adjustable launch trajectory hood.
